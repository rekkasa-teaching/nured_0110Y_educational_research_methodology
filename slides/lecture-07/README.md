# Παρουσίαση: Συλλογή ποιοτικών δεδομένων και αφηγηματική έρευνα

Ανοίξτε το `index.html` σε πρόγραμμα περιήγησης για να προβάλετε την έτοιμη παρουσίαση. Το HTML περιέχει τους απαραίτητους πόρους του και μπορεί να προβληθεί χωρίς σύνδεση στο διαδίκτυο.

Το `index.qmd` περιέχει τις διαφάνειες και τις σημειώσεις διδασκαλίας στα ελληνικά. Τα `custom.scss` και `logo.jpg` διατηρούν τη μορφοποίηση και το λογότυπο που δόθηκαν.

## Επεξεργασία και επαναδημιουργία

Αφού εγκαταστήσετε το [Quarto](https://quarto.org/docs/get-started/), μπορείτε να τροποποιήσετε το `index.qmd` και, από τον φάκελο που περιέχει τα αρχεία, να εκτελέσετε:

```bash
quarto render index.qmd
```

Η εντολή αναδημιουργεί το `index.html`. Οι σημειώσεις είναι διαθέσιμες στην προβολή ομιλητή του reveal.js με το πλήκτρο `S`· ενδέχεται να χρειαστεί να επιτρέψετε το αναδυόμενο παράθυρο.

Οι σημειώσεις περιλαμβάνουν ενδεικτικό σωρευτικό χρονισμό 120 λεπτών, οδηγίες για τις δραστηριότητες, ενδεικτικές απαντήσεις και παραπομπές στις σελίδες του σαρωμένου υλικού. Το πρόγραμμα δεν περιλαμβάνει διάλειμμα.
